# PixMind v2.3.0 — Hybrid Search UX Integration

Base: teammates' latest SmartStudio-main (FastAPI semantic search + real speech_to_text).

## Scope of this patch
- Keeps teammate semantic text search and real speech recognition.
- Keeps all AI models, OCR, face logic, thresholds, YOLO and visual embedding models unchanged.
- Restores compact Smart Search UX:
  - Photos shortcut in header.
  - Search/indexing settings behind a gear icon.
  - Language / media scope / General-Precise inside a compact options sheet.
  - Results placed directly after active search controls.
- Restores real Search-by-Image entry from Smart Search.
- Restores Visual Index management alongside AI Index.
- Presents semantic search as **Describe**, while microphone remains an input method.
- Adds semantic service information in Search & Indexing settings.
- Fixes bottom-navigation selected tab to follow the actual GoRouter route.

## Intentionally unchanged
- OCR models and OCR pipeline.
- Face detection / MobileFaceNet / clustering thresholds.
- YOLO / scene analysis.
- Image similarity thresholds and ranking.
- SQLite / ObjectBox architecture.
- FastAPI implementation (backend not included in the supplied project ZIP).
