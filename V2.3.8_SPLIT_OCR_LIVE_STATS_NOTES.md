# PixMind v2.3.8 — Split OCR + Live Smart Index Stats

Base: v2.3.7 Complete Smart Index final candidate.

## Stable changes

- Split the previous Content & Text pipeline into two resumable stages:
  1. **Content understanding**: YOLO objects, scene labels, named colors, metadata.
  2. **Text Recognition**: English ML Kit OCR + optional Arabic Tesseract OCR.
- `Index all content`, `Index next 20`, background Content indexing and Content progress no longer wait for OCR.
- Added independent OCR state (`ocr_index_state`) so OCR can run later without repeating Content, People, Gallery Analysis or Visual embeddings.
- Existing v2.3.7 OCR work is preserved during the database upgrade.
- Added manual OCR controls in Search -> Settings -> Text Recognition:
  - OCR next 20
  - Refresh OCR latest 20
  - Index all text
  - Arabic OCR on/off
- Complete Smart Index now has five stages:
  Gallery Analysis -> Content -> Text Recognition -> People -> Visual Search.
- Complete/Continue only fills missing work for each stage.
- Settings statistics now poll the real databases every 2 seconds while the sheet is open; the manual refresh button remains available.
- Clearing the search index also clears the independent OCR completion state.

## Deliberately unchanged

- Face v3 model, alignment, thresholds and clustering.
- YOLO model.
- Visual embedding models.
- Current OCR engines/models themselves (ML Kit + Tesseract).
- Face Sticker integration.
- Federated Search behavior.

## Arabic OCR behavior

When Arabic OCR is OFF, Text Recognition completes using the faster ML Kit Latin/English path. If Arabic OCR is later enabled, photos previously completed in English-only mode become eligible for the Arabic-enabled OCR stage without rerunning Content/People/Visual.

Legacy OCR completed before this split is preserved as completed during upgrade to avoid an expensive surprise re-index. Use **Refresh OCR latest 20** when you deliberately want to retest recent legacy photos.
