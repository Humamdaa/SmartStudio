# PixMind v2.3.9 — App-level Smart Index (Interview Candidate)

Built directly on v2.3.8 split-OCR/live-stats.

## What changed

- Complete/Continue Smart Index is now owned by the root Riverpod ProviderScope,
  not by SearchScreen.
- Switching Home / Search / Albums / For You no longer disposes the running
  Smart Index orchestration or the visual TFLite interpreters.
- Reopening Search attaches to the same live progress/state instead of creating
  a new Smart Index instance.
- Added a compact app-wide progress strip above the bottom navigation while the
  five-stage Smart Index is running. This makes it visible during the interview
  that indexing continues while the user browses other tabs.
- The Search settings card is now labelled "5-stage Smart Index pipeline" to
  communicate integration rather than five unrelated indexes.
- Existing stages remain unchanged and resumable:
  1. Gallery analysis
  2. Content understanding
  3. Text recognition
  4. People / Face v3
  5. Visual search embeddings

## Intentionally unchanged

- Face v3 model, alignment, thresholds and clustering
- OCR engines and split OCR state introduced in v2.3.8
- YOLO / scene analysis
- Federated search
- Background Content WorkManager
- Background People WorkManager
- Face Sticker / sharing integration
- Visual embedding models

## Background semantics

This change guarantees continuity while navigating inside the running app.
Content and People also retain their existing Android WorkManager background
paths. The entire five-stage orchestrator is not converted into one monolithic
WorkManager chain; if Android kills/force-stops the process, persisted stage
results remain resumable the next time Continue Smart Index is used.
