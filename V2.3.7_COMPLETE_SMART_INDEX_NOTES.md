# PixMind v2.3.7 — Complete / Continue Smart Index

Final interview polish on top of v2.3.6 Background & Performance.

## Added
- One user-facing **Complete Smart Index** card in Search → Settings.
- Unified progress for four existing specialized indexes:
  1. Gallery analysis — pHash, dominant color, quality.
  2. Content & text — YOLO objects, scene labels, named colors, OCR, metadata.
  3. People — Face v3 / MobileFaceNet clustering.
  4. Visual search — EfficientNet/projection embeddings.
- **Continue Smart Index** means resume missing work only. It does not reset or
  reprocess photos already complete for a stage.
- Arabic OCR still follows the existing Arabic OCR switch. When it is OFF, the
  content stage runs without Arabic OCR.
- Existing manual controls remain available: Index next 20, Refresh latest 20,
  Index all content, Face Lab, Background People and Visual Index.
- Unified count queries avoid loading huge id sets only to display progress.
- Full-content progress is now cumulative across internal 8-photo batches.

## Intentionally unchanged
- Face v3 model, alignment, thresholds and clustering.
- YOLO, scene, OCR models and OCR logic.
- Visual embedding models.
- Federated Search behavior.
- Background & Performance changes from v2.3.6.
- Face Sticker / teammate integration.

## Important behavior
The current stable content pipeline still treats Content + OCR as one completed
stage. If Arabic OCR is disabled while a photo becomes content-complete, simply
enabling Arabic later does not force all completed content photos to rerun.
Use Refresh latest 20 / a deliberate reindex for old photos if Arabic OCR must
be added later. This avoids silently re-running YOLO/scene work.

## Test checklist
1. Open Search → gear → Smart Index.
2. Confirm existing Gallery/Content/People/Visual counts are detected.
3. Press Continue Smart Index and verify already-complete stages are skipped.
4. Stop during a stage, reopen, press Continue and verify it resumes missing work.
5. Turn Arabic OCR OFF and verify the Content & text subtitle shows Arabic off.
6. Verify manual Index all content, Face Lab and Visual Index still work.
7. Re-test named-person search, color search, Image search, Describe and Face Sticker.
