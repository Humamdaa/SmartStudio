# PixMind v2.3.1 — Search Architecture Cleanup

This patch is intentionally narrow and is based on `PixMind-v2.3.0-hybrid-search-ux`.

## What changed

- Removed the user-facing `General / Precise` search-mode switch.
- The compact options summary now shows only query language and media scope.
- `All` is the local on-device keyword search across the existing AI index.
- Typed filters remain explicit and local: OCR, Object, Person, Scene, Date, Color.
- `Describe` remains the natural-language semantic text-to-image path that uses the FastAPI text-embedding service.
- Voice remains only an input method for `Describe` (speech -> editable text -> semantic search).
- `Image` remains the on-device image-to-image visual similarity search.
- Color-only local search now uses one stable tolerance (`0.32`) instead of changing with a removed mode toggle.

## Search families after this cleanup

1. Local structured/indexed search
   - All
   - OCR
   - Object
   - Person
   - Scene
   - Date
   - Color

2. Semantic text-to-image search
   - Describe
   - Voice is an input method for Describe

3. Visual image-to-image search
   - Image

## What was NOT changed

- OCR pipeline
- Face detection / recognition / clustering
- YOLO
- EfficientNet image embeddings
- Image projection model
- FastAPI client or backend protocol
- SQLite / ObjectBox architecture
- Visual similarity ranking / thresholds
- Background indexing

## Note about old internal class names

Some internal classes still use historical names such as `PreciseSearchRepository` and `PreciseIndexer`. They are implementation names and are not the removed UI concept. They were deliberately not renamed in this final-stability patch to avoid an unnecessary refactor before presentation.
